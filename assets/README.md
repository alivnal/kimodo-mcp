# assets

`characters/Y Bot.fbx` is the default Mixamo target for the FBX export (`target_fbx` in a spec). It is not shipped
here: download Y Bot (T-pose, FBX) from [mixamo.com](https://www.mixamo.com) and save it as
`assets/characters/Y Bot.fbx`, or point `target_fbx` at any Mixamo-rigged character (`mixamorig:` bones).
